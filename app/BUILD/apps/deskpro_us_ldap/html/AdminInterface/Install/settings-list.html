You can specify an account filter format here. You can leave this field blank to use the default account filter format, which is: (|(dn=%1$s)(mail=%1$s)(uid=%1$s))

Service Account

The service account is the account used to initially bind to the LDAP directory. The service account must have sufficient permission to run filter queries against the directory. Make sure to specify the full DN for the account name. For example, CN=Deskpro,DC=example,DC=com.

Please enter your service user.
