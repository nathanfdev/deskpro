The FQDN name for users in this directory. For example, a user alice@acme.com would usually have a domain of acme.com.
This option should be used to specify the NetBIOS domain name for Windows networks. This option is not required but if it is not supplied, usernames in backslash form (e.g., ACME\alice) are not supported.
