DEVELOPMENT INSTALL: Windows
============================

REQUIREMENTS
============

- Windows XP or later.


Install Git
===========

You first need to install Git. Follow this guide on GitHub: http://help.github.com/win-set-up-git/

Make sure to follow the instructions about setting up an SSH key as well, and add it to your GitHub account so you can properly checkout the private DeskPRO repository.

Due to a bug in msysgit, you must also add it's bin directory to your PATH:

1. From the Start menu right click `My Computer` and click `Properties`
2. In the `System Properties` window, click on the `Advanced` tab
3. Click on the `Environment Variables` button
4. Find the `Path` variable in the list and double-click to edit it
5. Append `;C:\Program Files (x86)\Git\bin` to the existing value. That is a semi-colon followed by the path to the msysgit `bin` directory.

Install WAMP
============

WAMP is a package that includes Apache, MySQL and PHP in one easy application. Download it here: http://www.wampserver.com/en/

After installation, choose to "Launch WAMP server now." If you missed this option, you can launch WAMP manually from the start menu.

Change PHP Version
==================

Some versions of WAMP default to using an older version of PHP, but a newer version is still bundled with the app. To change the version, find the WAMP icon in the status area of the task bar (the green "W"). Click on it, and under PHP > Version, switch it to any version that is >= 5.3.2.

Create Database
===============

In the status area of the task bar there will be a new WAMP icon (the green "W"). Click the icon to bring up the WAMP menu, and click on "phpMyAdmin" to launch phpMyAdmin in your browser. Alternatively, you can manually browse to `http://localhost/phpmyadmin/`

1. In phpMyAdmin, click on the "Privileges" tab.
2. Click on "Add New User"
3. Enter the following details:
    - Username: deskpro
    - Host: Change the select box to `Local`
    - Password: deskpro
    - Under "Database for user" choose "Create database with same name and grant all privileges"
    - Click on "Go" to save the user and create the database.

Clone Repository
================

Open the "Git Bash" application that was installed alongside Git for Windows in the first step. This should be in the Start menu under the "Git" folder.

Enter these commands:

    $ cd /c/wamp/www
    $ git clone git@github.com:DeskPRO/DeskPRO.git
    $ cd DeskPRO
    $ git submodule init
    $ git submodule update
    $ cd appfiles/vendor/zend1
    $ git reset --hard
    $ cd /c/wamp/www/DeskPRO/appfiles
    $ cp config.new.php config.php

Note: Some of these commands (especially `git submodule update`) can take a long time depending on your internet connection.

Note: If you get an error alert from `git submodule init` then please ensure the `Path` environmental variable was properly set in the first step.
You may get many error alerts in `git submodule update`, you can just ignore those.

After these commands have executed, you will have cloned all of the DeskPRO source files into the folder at `C:\wamp\www\DeskPRO`

Edit Config
===========

Click on the green "W" icon in the status area again and this time click on the "www directory" item to open Explorer.

Navigate deeper into `DeskPRO\appfiles` and open `config.php` in Notepad or your favourite editor.
(The full path to the file is therefore `C:\wamp\www\DeskPRO\appfiles\config.php`)

Edit the database values to set `user`, `password` and `database` to `deskpro`. Save and close the file.

Run Installer
=============

Open your browser and navigate to `http://localhost/DeskPRO/index_dev.php/_sys/install` and follow the on-screen instructions.

After you've reached the end of the Installation Wizard, an initial admin account will be created that you can use to log in.
Navigate to http://localhost/DeskPRO/index_dev.php/agent/ and log in with `admin@example.com` with password `pass`

Note: The /index_dev.php/ prefix is important as it loads the dev environment which some things are currently tied to.

Note: The first time you run a page from any section (/, /agent/ or /_sys/), Symfony will take a while to generate a bunch of cache files. Subsequent page loads will be much quicker.
