DEVELOPMENT INSTALL
===================


REQUIREMENTS
============

- PHP 5.3.2 or later
-- `pdo` and `pdo_mysql` extensions
-- `intl` extension. (See note 1)

- MySQL 5.1.41 or later

	Note (1):
	The `intl` extension is bundled with PHP, however some distros do not ship it.
	You can easily use PECL to install the extension, or your package manager may
	have a package for it. For example, with Ubuntu: apt-get install php5-intl


Vendors
=======

Vendors are tracked as git submodules. Git does not automatically download submodules, so you have to clone these repositories manually by running two git commands:

	git submodule init
	git submodule update

This will initiate the submodules in your git tree, and then clone the repositories, and finally the correct revision will be checked out.

If you use SmartGit, choose Remote -> Submodule from the menu to get to these commands.


Edit Config
===========

- Copy `/appfiles/config.new.php` to `/appfiles/config.php`
- Edit `/appfiles/config.php` with your database details.


RUN INSTALL
===========

In your web browser, visit the on-screen installer:

	/index_dev.php/dev/install


Log In
================

View `/index_dev.php/agent/` in your browser and log in with the created admin account.
