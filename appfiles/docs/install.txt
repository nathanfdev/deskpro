DEVELOPMENT INSTALL
===================


File Permissions
================

Make sure the following directories exist and are writable:

- `/appfiles/sys/cache`
- `/appfiles/sys/logs`


Edit Config
===========

Edit `/appfiles/config.php` with your database details.


Run Dev Commands
================

From the console, run the two dev commands.

To create the database and schema:

	$ cd appfiles/bin
	$ ./console-dev dpdev:new-install

To fill in the default data:

	$ ./console-dev dpdev:new-install-data


NOTES:

- The `dpdev:new-install` command will drop the database if it doesn't exist.
- The `dpdev:new-install` command dynamically generates the schema based on the defined entities. If an entity is incorrect/invalid, then the command will fail. You'll need to either fix the bug or revert to a previous working revision.
- The `dpdev:new-install-data` creates an admin user with email "admin@example.com" and password "pass".
