DEVELOPMENT INSTALL
===================


File Permissions
================

Make sure the following directories exist and are writable:

- `/appfiles/sys/cache`
- `/appfiles/sys/logs`

On Linux, make sure the following files are executable:

- `/appfiles/bin/console`
- `/appfiles/bin/console-dev`
- `/appfiles/bin/install_vendors.sh`
- `/appfiles/bin/update_vendors.sh`


Vendors
=======

1. Delete the directory `/appfiles/vendor`
2. Extract `/appfiles/docs/vendors.tgz` and move the directory to `/appfiles/vendor`

The vendors can alternatively be downloaded separately from their sources. This is automated by the `/appfiles/bin/install_vendors.sh` shell script on Linux:

	$ cd appfiles/bin
	$ ./install_vendors.sh
	Initialized empty Git repository # etc

This will pull the latest revisions from each repository which might break the system. Stick with vendors.tgz which is known to work.


Edit Config
===========

Edit `/appfiles/config.php` with your database details.

Edit `/sys/config/config.yml` and find the line for `assets_base_urls` and edit it for your web path. (This won't be necessary soon, but needed for now).


Run Dev Commands
================

From the console, run the two dev commands.

To create the database and schema:

	$ cd /srv/www/dp_400/appfiles/bin
	$ ./console-dev dpdev:new-install

To fill in some initial data:

	$ ./console-dev dpdev:new-install-data

Or on Windows, for example using WAMP:

	> cd C:\wamp\www\dp_400\appfiles\bin
	> C:\wamp\bin\php\php5.3.0\php.exe console-dev dpdev:new-install
	> C:\wamp\bin\php\php5.3.0\php.exe console-dev dpdev:new-install-data

If something fails, you can use the `-v` switch to get more information with a backtrace:

	$ ./console-dev dpdev:new-install -v

NOTES:

- The `dpdev:new-install` command will DROP the database if it exists! Make a backup if you want to keep it.
- The `dpdev:new-install` command dynamically generates the schema based on the defined entities. If an entity is incorrect/invalid, then the command will fail. You'll need to either fix the bug or revert to a previous working revision.
- The `dpdev:new-install-data` creates an admin user with email "admin@example.com" and password "pass".


Log In
================

View `/index_dev.php/tech/` in your browser and log in with the created admin account.
