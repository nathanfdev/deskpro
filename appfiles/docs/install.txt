DEVELOPMENT INSTALL
===================


REQUIREMENTS
============

- PHP 5.3.2 or later
-- `pdo` and `pdo_mysql` extensions
- MySQL 5.1.41 or later


Cloning The Repository
======================

Use git to clone the DeskPRO repository at https://github.com/DeskPRO/DeskPRO

For example:

    git@github.com:DeskPRO/DeskPRO.git

You may need to add your computers key to your GitHub account at https://github.com/account/ssh

Vendors
=======

Vendors are tracked as git submodules. Git does not automatically download submodules, so you have to clone these repositories manually by running two git commands:

	git submodule init
	git submodule update

This will initiate the submodules in your git tree, and then clone the repositories, and finally the correct revision will be checked out.

If you use SmartGit, choose Remote -> Submodule from the menu to get to these commands.

This step may take a while to download all of the vendor repositories.

File Permissions
================

Make sure `/appfiles/sys/cache` is writable. For example:

    chown -R 0777 appfiles/sys/cache


Edit Config
===========

Create a MySQL database and then edit your config file:

- Copy `/appfiles/config.new.php` to `/appfiles/config.php`
- Edit `/appfiles/config.php` with your database details.

RUN INSTALL
===========

In your web browser, visit the on-screen installer:

	/index_dev.php/dev/install

Note the admin account credentials created.

Note: The first time you try to bring up the page it may take a long time.
This is because Symfony is generating all of the cache files for the first time.

Log In
================

View `/index_dev.php/agent/` in your browser and log in with the created admin account.
